# Reduced-Order-Modelling-of-Resin-Infusion-Permeability-in-GFRP-Composites
Simulation of 1D resin flow in glass-fibre composites. Uses Darcy's law and Gebart micromechanics to link fibre packing to permeability and filling time. Includes numerical solvers, process window mapping, and Capillary Number analysis to predict manufacturing void defects.
